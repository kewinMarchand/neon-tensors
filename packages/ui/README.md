# @kewinmarchand/ui

Composants commons **génériques** pour les monorepos Neon (`neon-games`, `neon-tensors`).

- **Shell de jeu** (`mountGameFrame`) : cadre identique pour tous les jeux — header / zone centrale (jeu) / panneaux latéraux, viewport `100vh`, zone centrale centrée, options spécifiques dans les panneaux latéraux.
- Composants utilitaires : `createRepoLink`.
- Le thème visuel Neon vient du paquet `@kewinmarchand/theme-neon` ; ce paquet ne fournit aucune identité visuelle propre.

Conforme à l'[ADR-0002](../../boilerplates-commun/doc/adr/0002-composants-communs-et-theme-neon.md) et à l'[ADR-0003](../../boilerplates-commun/doc/adr/0003-structure-des-monorepos.md) du chantier de consolidation.

# @kewinmarchand/theme-graphite

Thème **Graphite** : tokens, variables CSS et overrides, **attachés aux composants commons** de `@kewinmarchand/boilerplates-ui`.

- **Pas de composants thématiques dédiés** : toute brique UI réutilise un composant commun ; toute identité visuelle passe par ce thème Graphite.
- Tokens exposés sur la variable `--bui-*` (couleurs, surfaces, texte, typo, espacements, radii, ombres, focus, motion, conteneurs, z-index).
- Overrides `[data-a11y-mode="enhanced"]` et `prefers-reduced-motion`.
- Consommé par les monorepos.

Conforme à l'[ADR-0002](../../boilerplates-commun/doc/adr/0002-composants-communs-et-theme-graphite.md) du chantier de consolidation.

# @kewinmarchand/theme-neon

Theme **Neon** : tokens, variables CSS et overrides, **attachés aux composants commons** de `@kewinmarchand/boilerplates-ui`.

- **Pas de composants « Neon »** : toute brique UI réutilise un composant commun ; toute identité visuelle Neon passe par ce thème.
- Tokens exposés sur la variable `--bui-*` (couleurs, surfaces, texte, typo, espacements, radii, ombres, focus, motion, conteneurs, z-index).
- Overrides `[data-a11y-mode="enhanced"]` et `prefers-reduced-motion`.
- Consommé par les monorepos `neon-games` et `neon-tensors`.

Conforme à l'[ADR-0002](../../boilerplates-commun/doc/adr/0002-composants-communs-et-theme-neon.md) du chantier de consolidation.
